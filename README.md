🍽️ Lezzet Pikseli | Next-Gen Restaurant Automation & Management System
Lezzet Pikseli is a comprehensive, full-stack restaurant management solution built on modern backend principles. It digitizes traditional restaurant operations to maximize efficiency and user experience.

⚠️ Project Status: This repository serves as a Technical Showcase. As the project is being prepared for commercial use, the source code remains private. Technical depth is demonstrated through the documentation and video walkthroughs below.

👥 Contributors & Roles
Ulviye Gülnihal Yüksel: Backend Architecture, Relational Database Design (MS SQL), Security Protocols, Business Logic, and Deployment.

Emine Kömürcü: Frontend UI/UX Design, Responsive Layout Implementation, and Visual Assets.

🛠️ Tech Stack
Framework: .NET 9.0 (ASP.NET Core MVC).

Data & ORM: Entity Framework Core (Code-First), MS SQL Server.

Frontend: Bootstrap 5, JavaScript (ES6+), jQuery, Ajax.

Architecture: Dependency Injection (DI), Area-Based Routing (Admin/Default), N-Tier logic.

Security: Cookie-Based Authentication, Role-Based Authorization, Anti-Forgery Tokens (CSRF protection).

✨ Core Features & Video Walkthroughs
1. Menu, Authentication & UX
Comprehensive user flow including dynamic menu browsing and secure account management.

Features: Dynamic category listing, secure login/register, and responsive UI.

📺 Watch Demo: Menu & Authentication

2. Ordering Flow & Progress Tracking
A seamless end-to-end ordering experience with real-time feedback.

Features: LocalStorage-based cart management, automated order creation, and a dynamic progress bar tracking ("Received" to "Delivered").

📺 Watch Demo: Ordering & Real-time Tracking

3. Admin Management & CMS
Powerful back-office tools for restaurant owners to control every aspect of their digital presence.

Features: Full CRUD for categories/products, reservation management (Approve/Edit/Delete), automated folder hierarchy for assets, and GUID-based file naming.

📺 Watch Demo: Admin Operations & CMS

🏗️ Engineering Highlights
Automated Asset Management: Custom logic to sanitize file names and use GUIDs to prevent server-side naming conflicts.

Relational Integrity: Implemented 1:N relationships between Categories, Products, and Orders using Fluent API.

Server-Side Paging: Optimized Admin Dashboard performance using .Skip() and .Take() methods for handling large datasets.
